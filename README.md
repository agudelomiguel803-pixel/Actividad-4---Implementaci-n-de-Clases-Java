# Implementación de Clases en Java

## Descripción
Este proyecto demuestra la implementación de clases en Java utilizando:

- Atributos
- Constructores
- Métodos Getter
- Métodos Setter
- Método toString()

El proyecto contiene una clase `Product` y una clase `Main` para probar el funcionamiento de los objetos.

## Estructura del Proyecto

src/main/java/com/example/

- Main.java
- Product.java

## Características

- Clase `Product` con 5 atributos:
  - id
  - name
  - price
  - stock
  - available

- Constructor por defecto
- Constructor parametrizado
- Métodos getter
- Métodos setter
- Validaciones en los setters
- Método `toString()` personalizado

## Cómo Compilar

```bash
javac src/main/java/com/example/*.java
